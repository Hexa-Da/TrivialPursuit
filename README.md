# Trivial Pursuit Android

Une application Android qui recrée le célèbre jeu de société Trivial Pursuit avec des fonctionnalités modernes et une interface utilisateur intuitive.

## Fonctionnalités

- **Mode Jeu Classique** : Jouez au Trivial Pursuit traditionnel avec jusqu'à 6 joueurs
- **Mode Entraînement** : Améliorez vos connaissances dans une catégorie spécifique
- **6 Catégories** :
  - Géographie
  - Histoire
  - Divertissement
  - Art et Littérature
  - Sciences et Nature
  - Sports et Loisirs
- **20 Questions par Catégorie** : Un large éventail de questions pour chaque thème
- **Système de Score** : Suivez les progrès de chaque joueur
- **Interface Intuitive** : Design moderne et facile à utiliser
- **Tolérance aux Réponses** : Système intelligent qui accepte les variations orthographiques et les réponses partielles

## Installation

1. Clonez le repository :
```bash
git clone https://github.com/votre-username/TrivialPursuit.git
```

2. Ouvrez le projet dans Android Studio

3. Synchronisez le projet avec Gradle

4. Exécutez l'application sur un émulateur ou un appareil Android

## Configuration Requise

- Android Studio Arctic Fox ou version ultérieure
- Android SDK 21 ou version ultérieure
- Gradle 7.0 ou version ultérieure

## Comment Jouer

1. **Lancement du Jeu**
   - Choisissez le nombre de joueurs (2-6)
   - Entrez les noms des joueurs
   - Sélectionnez le mode de jeu (Classique ou Entraînement)

2. **Mode Classique**
   - Chaque joueur lance le dé à tour de rôle
   - Répondez à une question de la catégorie correspondante
   - Gagnez un point de couleur en répondant correctement
   - Le premier joueur à gagner tous les points de couleur remporte la partie

3. **Mode Entraînement**
   - Choisissez une catégorie
   - Répondez aux questions pour améliorer vos connaissances
   - Votre score est enregistré pour suivre vos progrès
